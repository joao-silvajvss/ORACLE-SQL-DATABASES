# 🗄️ Banco de Dados & SQL (MySQL e Oracle)

Repositório dedicado ao armazenamento de scripts SQL, modelagens de banco de dados e exercícios práticos desenvolvidos na **faculdade, cursos livres e estudos autônomos**.

---

### 📜 Certificações Relacionadas

- 🎓 **Oracle Database Foundations (90h)** — Oracle Academy
- 🎓 **Oracle Database Design (90h)** — Oracle Academy

---

### 📂 Estrutura do Repositório

- **`/01-modelagem-de-dados`**: Modelos conceituais e lógicos (DER) criados no **brModelo** antes do desenvolvimento do código SQL.
- **`/02-ddl-estruturas`**: Scripts de criação e alteração de bancos e tabelas (`CREATE DATABASE`, `CREATE TABLE`, `ALTER TABLE`, PK/FK).
- **`/03-dml-manipulacao`**: Comandos de inserção, atualização e exclusão de dados (`INSERT`, `UPDATE`, `DELETE`).
- **`/04-consultas-e-filtros`**: Queries com `SELECT`, filtros (`WHERE`), ordenação (`ORDER BY`) e agrupamento (`GROUP BY`, `HAVING`).
- **`/05-juncoes-e-relacionamentos`**: Consultas em múltiplas tabelas via `INNER JOIN`, `LEFT JOIN` e `RIGHT JOIN`.

---

### 🛠️ Tecnologias e Ferramentas

- **SGBDs Relacionais:** MySQL, Oracle Database
- **Linguagem:** SQL (Structured Query Language)
- **Modelagem de Dados:** brModelo, Oracle SQL Developer Data Modeler
- **Gerenciadores & IDEs:** MySQL Workbench, DBeaver, Oracle SQL Developer, Oracle Live SQL

### 🚀 Como Visualizar e Executar

1. **Diagramas / Modelagem:** Abra os arquivos de modelo conceitual/lógico no software **brModelo** ou visualize os esquemas exportados em imagem.
2. **Scripts SQL:** Abra sua ferramenta de preferência (MySQL Workbench, DBeaver ou Oracle Live SQL) e execute os arquivos `.sql` no editor de queries.
