# 🗄️ Banco de Dados & SQL (MySQL e Oracle)

Repositório dedicado ao armazenamento de scripts SQL, modelagens e exercícios de banco de dados desenvolvidos na **faculdade, cursos da Oracle Academy e estudos autônomos**.

---

### 📜 Certificações Relacionadas

- 🎓 **Oracle Database Foundations (90h)** — Oracle Academy
- 🎓 **Oracle Database Design (90h)** — Oracle Academy

---

### 📂 Estrutura do Repositório

- **`/01-modelagem-de-dados`**: Diagramas Entidade-Relacionamento (DER), modelos conceituais, lógicos e regras de negócio.
- **`/02-ddl-estruturas`**: Scripts de criação e alteração de tabelas e bancos (`CREATE DATABASE`, `CREATE TABLE`, `ALTER TABLE`, PK/FK).
- **`/03-dml-manipulacao`**: Comandos de manipulação de dados (`INSERT`, `UPDATE`, `DELETE`).
- **`/04-consultas-e-filtros`**: Queries com `SELECT`, filtros (`WHERE`), ordenação (`ORDER BY`) e agrupamento (`GROUP BY`, `HAVING`).
- **`/05-juncoes-e-relacionamentos`**: Consultas em múltiplas tabelas via `INNER JOIN`, `LEFT JOIN` e `RIGHT JOIN`.

---

### 🛠️ Tecnologias e Ferramentas

- **SGBDs Relacionais:** MySQL, Oracle Database
- **Linguagem:** SQL (Structured Query Language)
- **Ferramentas:** MySQL Workbench, DBeaver, Oracle SQL Developer, Oracle Live SQL

---

### 🚀 Como Executar os Scripts

1. Abra sua ferramenta de preferência (MySQL Workbench, DBeaver ou Oracle Live SQL).
2. Conecte-se ao seu ambiente local ou servidor.
3. Copie ou abra o arquivo `.sql` desejado e execute as instruções no editor de queries.
