# ⚽ Projeto Banco de Dados — Brasileirão 2026

Projeto focado na modelagem e implementação de um banco de dados relacional para o gerenciamento de dados e partidas do campeonato Brasileirão 2026.

---

### 🔄 Fluxo de Desenvolvimento

1. **Modelagem Conceptual e Lógica:** Diagrama Entidade-Relacionamento (DER) elaborado no **brModelo**.
2. **Implementação Física:** Criação de tabelas, restrições de integridade (PK/FK) e inserções de dados executadas no **MySQL**.

---

### 📂 Arquivos do Projeto

- `BANCO DE DADOS - BRASILEIRAO 2026 - FINAL.brM3`: Arquivo de modelagem relacional para o software brModelo.
- `BRASILEIRAO_2026.sql`: Script contendo a estrutura do banco (`CREATE DATABASE`, `CREATE TABLE`) e dados populados (`INSERT`).
